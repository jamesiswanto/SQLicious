# SQLicious 🍽️  

## Restaurant Order Analysis Using SQL  

**SQLicious** is a data analysis project focused on extracting insights from restaurant order data using SQL queries. The project explores menu details, order trends, and customer behavior to derive meaningful conclusions.  

---  
## 📌 Objectives  

### **Objective 1: Explore the Items Table**  
1. View the `menu_items` table and write a query to find the number of items on the menu.  
2. Identify the least and most expensive items on the menu.  
3. Determine the number of Italian dishes on the menu and find the least and most expensive ones.  
4. Categorize dishes and calculate the average price per category.  

### **Objective 2: Explore the Orders Table**  
1. View the `order_details` table and determine the date range of the data.  
2. Find the total number of orders and items ordered within this range.  
3. Identify the orders with the most items.  
4. Count how many orders contained more than 12 items.  

### **Objective 3: Analyze Customer Behavior**  
1. Combine `menu_items` and `order_details` tables for better analysis.  
2. Identify the least and most ordered menu items along with their categories.  
3. Find the top 5 highest-spending orders.  
4. Analyze the details of the highest-spending order and extract insights.  
5. (Bonus) Examine the top 5 highest-spending orders and gather key insights.

## 🚀 How to Run the Queries  
1. Import the dataset into your SQL database.  
2. Open your SQL client or command-line tool.  
3. Run the queries from the `queries/` folder to explore the dataset.

## 📊 Key Insights  
- The restaurant offers a diverse range of dishes across multiple categories.  
- Some dishes are significantly more popular than others.  
- Large orders contribute significantly to overall revenue.  
- Certain categories have higher-priced items that drive order value.
